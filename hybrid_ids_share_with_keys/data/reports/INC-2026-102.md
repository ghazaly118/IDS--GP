# Incident Investigation Report: INC-2026-102
## Executive Summary
On June 24, 2026, a massive UDP denial-of-service flood was detected hitting **prod-web-01** (10.0.0.5). Bandwidth utilization spiked to 582MB in a 15-second window, causing temporary latency on HTTP services.

## Threat Analysis & Indicators
- **Attacker IP**: `185.220.101.5`
- **Target Host**: `prod-web-01` (10.0.0.5)
- **Protocol/Port**: UDP / 80
- **MITRE Mapping**: T1498.001 - Direct Network Flood
- **Calculated CVSS Severity**: **9.1 (Critical)**

## Action Taken
1. Automated IR trigger isolated `prod-web-01` using Local Agent firewall policies.
2. IP `185.220.101.5` was added to the distributed blocklist file.
3. Service has stabilized, and normal traffic routing was restored via fallback server.
